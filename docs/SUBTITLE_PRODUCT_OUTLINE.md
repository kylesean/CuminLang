# CuminLang 智能字幕引擎：产品特性与设计纲要（草稿参考）

> **文档定位**：本文档并非完整的产品说明书，而是供后续撰写官网介绍、用户手册与功能宣传页时使用的**产品思路骨架与核心卖点提炼**。内容完全对应系统已落地的实际能力。

---

## 一、产品设计意图（Why：为什么我们要重构字幕体系）

在绝大多数通用播放器或早期语言学习工具里，字幕只是视频文件旁路挂载的「一次性展示文本」。这给认真学英语的人带来了四重隐形伤害：

1. **假“完美”与伪标准**：YouTube 自动字幕或残缺外挂字幕往往时间重叠、半句腰斩、夹杂 `[music]`/`[applause]` 噪音、人名与专业词汇拼写漂移——直接用来精听复读，会打断语感甚至误导跟读评分。
2. **盲目重识别的代价**：如果一刀切用本地语音模型覆盖原字幕，原本作者写得很好的大小写、标点和罕见人名/专有名词反而可能丢失。
3. **跨版本学习资产断裂**：用户好不容易在一条字幕上攒下的收藏金句、AI 精析笔记和跟读打分记录，一旦更换更优轨道或手工改了一个错词，过去往往因为哈希变化而“瞬间消失”。
4. **越整理越乱**：很多播放器每次加载都会重新按规则切句，用户好不容易拆好的句子，下次打开又被自动合并回原样。

**CuminLang 的核心产品哲学**：
> **把字幕当作一等语言学习底座，而不是消费即弃的文本流。**  
> 让「音频（本地声学模型）」只负责它最擅长的**词级精确时间、真实停顿与内容完整度**；让「参考文本与用户本人」负责**专有名词、拼写与语义表达**；并且**一切增强与改写永不破坏原始轨道与既有学习沉淀**。

## 二、核心用户价值与卖点总览

| 核心命题 | 对用户的直观价值 | 底层机制 |
| :--- | :--- | :--- |
| **开箱即用，不绑架本地模型** | 哪怕没下载语音模型，外挂/平台字幕也能立即清洗杂音并按完整意群秒开播放 | 独立前置清洗 + 统一意群分段引擎 |
| **真假字幕自动体检** | 真正高质量的人工字幕绝不打扰；伪装成人工轨的滚屏自动字幕与大段漏翻轨会被精准揪出 | 基于时间重叠率、舞台噪音比与低词速空洞的多维诊断 |
| **越听越准：音文双向融合** | 同时拿到作者的正确拼写/人名，以及声音级别的精准起止时间戳 | 本地 ASR（Parakeet / whisper.cpp）+ 外部文稿双向对账融合 |
| **完全本地、隐私且零费用** | 不上传用户私密视频，不消耗云端 API 额度，离线环境也能后台静默完成字幕升级 | 端侧 638MB 量化模型本地推理，就绪后静默处理 |
| **改一字即永久生效且不断播** | 看视频时发现错词，右侧双击改完回车即生效；断句、并句、原句试听一气呵成 | 原地行内编辑 + 音节加权拆句 + L3 最高权威直读 |
| **轨道可随时对比与回退** | 任何升级、精修与编辑都会生成独立伴生轨，绝不毁坏原字幕 | L3 > L2 > L1 三层非破坏式轨道体系 + 一键切换 |
| **学习记录永远跟着“这句话”走** | 从粗糙外挂升级到本地精修、再手工精校，收藏、笔记与跟读历史自动无感迁移 | 事务级学习资产跨 `fileHash` 重映射引擎 |

## 三、核心功能模块纲要（供拆解扩展为完整文档章节）

### 1. 智能轨道识别与真假字幕诊断
- **突破纯文件名迷信**：不只看是不是 `.en-orig.srt` 或 `.en.srt`，而是结合字幕正文做内容级诊断：
  - **识别伪装自动字幕**：捕获相邻句大面积时间轴重叠（滚屏效应）以及高比例 `[music]`/`>>` 非人声舞台标记；
  - **识别残缺或时间轴异常轨**：捕获持续超长却几乎没有有效单词的“时间轴空洞”，识别潜在大段漏译/漏字；
  - **克制提示**：经诊断确认为干净人工字幕（`author`）或已精修/已编辑轨道时，**绝不弹出多余的“重识提示条”**。

### 2. 三层非破坏式轨道架构（L3 > L2 > L1）
在硬盘同目录下以清晰后缀隔离不同权威等级，所有轨道保留完好并在控制面板可见、可随时切换对比：
- **L1 原始外部轨**（`.en.srt` / `.en-orig.srt` / 外挂字幕）：只作为素材输入与兜底回退，**系统永远只读不写**。
- **L2 本地声学精修轨**（`<视频名>.local.srt`）：本地识别或音文对账生成；一旦落盘即定型，加载时严格 1:1 直读。
- **L3 人工编辑轨**（`<视频名>.edited.srt`）：用户在文稿区亲手修正后的成果；拥有**全系统最高权威**，后台自动精修永远绕行，保证所改即永久所得。

#### 2.1 自动挂载顺序（打开视频时默认用哪条）

应用产出的权威轨**永远排在下载来的外部轨之前**——否则你辛苦生成的精修成果会被同名的 `.en.srt` 顶掉，
表现为「明明生成过更好的字幕，播放时却还挂着平台自动字幕」。

| 优先级 | 文件后缀 | 来源 | 说明 |
| :--- | :--- | :--- | :--- |
| 1（最高） | `.edited.srt` | 你在文稿区手改 | 改了什么就是什么，后台永不覆盖 |
| 2 | `.local.srt` | 本地识别 / 音文对账 | 已有词级时间戳，跟读最准；已按需融合作者轨的专名拼写 |
| 3 | `.en.srt` | 作者上传（人工字幕） | 标点与大小写规范，但时间轴为整句粒度 |
| 4 | 无后缀同名 | 外挂主字幕 | 视为该视频的默认字幕 |
| 5 | `.zh.srt` 等其它语言 | 下载 / 外挂 | 英语学习场景下优先级较低 |
| 6（最低） | `.en-orig.srt` | YouTube 自动字幕 | 无标点、时间轴滚动重叠、含 `[Music]` 噪音 |

> 注意：`.en.srt` 不一定等于「人工字幕」。有些视频作者没上传字幕，YouTube 会把自动生成的字幕
> 同时以 `en` 和 `en-orig` 两个名字提供，此时两份内容完全相同。所以应用**不只看文件名，
> 还会读内容做体检**（时间轴重叠率、舞台噪音占比、超长空洞），把伪装成 `.en.srt` 的自动字幕识别出来。

#### 2.2 怎么选：按你的目标挑

| 你的目标 | 推荐做法 | 理由 |
| :--- | :--- | :--- |
| **跟读 / 影子练习**（要精确到词） | 用 `.local.srt`（本地重识） | 只有本地声学模型能给出词级起止时间；平台字幕是整句粒度，逐词高亮会飘 |
| **快速精读**（要读得顺、标点对） | 有高质量作者轨时可手动切到 `.en.srt` | 人工校对的标点与大小写更自然，适合通读与理解 |
| **只想看懂大意** | 保持默认，不必下载模型 | 平台字幕也能用，应用会清洗噪音并按意群重新断句 |
| **想要「两者兼得」** | 开「后台自动精修字幕」 | 本地模型会在后台用声学时间轴重构、同时抢救作者轨里的专名拼写，产出 `.local.srt` |
| **已经手改过一批句子** | 什么都不用做 | `.edited.srt` 优先级最高，切轨、重识别都不会覆盖你的修改 |

#### 2.3 提示条什么时候出现、什么时候不出现

提示条只在**当前字幕确实可能有质量问题**时出现，不是每个视频都弹：

- **会提示**：当前挂的是平台自动字幕（`.en-orig.srt`，或内容体检判定为 ASR 的 `.en.srt`）；
  或当前轨存在大段漏段 / 超长空洞。
- **不会提示**：当前挂的是 `.local.srt`、`.edited.srt`，或经体检确认干净的人工字幕（`author`）。

提示条右侧的动作随状态变化：

| 状态 | 按钮 | 效果 |
| :--- | :--- | :--- |
| 还没有本地轨 | **本地重识** | 启动本地识别，生成 `.local.srt` |
| 已有本地轨 | **切到本地** | 一键切到 `.local.srt`，不重新识别 |
| 识别进行中 | 显示进度 + **取消** | 可中途取消，已完成的进度保留 |
| 你不想再看 | **暂不提示** | 记住这个视频的选择，下次不再弹 |

### 3. 全链路洁净清洗与“意群优先”统一排版
- **精准剥离非人声干扰**：清除 `[Music]`、`[Applause]`、`♪` 等听障/舞台标签与无效说话人前缀，同时**保留 `(about)` 这类正常口语补充括号**，避免学习文本与跟读评分被噪音污染。
- **停顿感知滚动去重**：自动合并 YouTube 逐词滚屏造成的重复句尾，但在遇到 `>= 1.0s` 真实说话停顿时绝不错误跨越合并。
- **统一动态规划（DP）意群切分**：无论来自外部清洗还是本地声学识别，最终全部归口到同一套切分内核——不把句末标点溢流到下一句开头、不在真实长停顿处硬连、不在虚词（如 `to` / `the`）处生硬折断、兼顾自然阅读句长与语速舒适度。

### 4. 本地 ASR 音文双向对账与后台无感升级
- **“各取所长”的对账融合（而非简单粗暴重来）**：
  - 当外部轨为高质量人工文稿且覆盖完整时（**保文校时模式**）：完整保留原作者的大小写、标点与专业术语，但用本地声学识别测出的真实词级起止时间彻底重构时间轴，消除滞后与飘移。
  - 当外部轨为自动字幕、漏段或错词较多时（**声学救稿 + 专名抢救模式**）：以完整性与标点更佳的本地识别序列为主干，反向从对齐时间窗内“抢救”出罕见专有名词（如人名、品牌名）的高准确拼写。
  - 当视频完全没有字幕时：直接由本地声学引擎端到端生成标准化 `.local.srt`。
- **后台静默热切换**：在设置开关开启（默认开启）且本机模型已就绪时，新导入或打开仅含 L1 字幕的视频可在后台低干扰排队精修；完成后原地无缝刷新字幕轨，**不打断视频播放、不重置播放进度**，且面板提供开关随时控制。

### 5. 右侧文稿原地精校与听校一体体验
- **无打扰原地改写**：在逐句模式与连贯讲稿模式下，双击英文句（或悬停点击编辑按钮）即可就地进入与正文完全等字号、左对齐的行内编辑状态——不弹窗、不跳页。
- **听校闭环与高效边界微调**：
  - 编辑框内置本句即时重播入口，边听原声边改错词；
  - 支持在光标位置直接**拆成两句**（按左右音节权重智能切分时间边界，保证每句可读最小时长）以及一键**并入下一句**；
  - 支持多步 **`Cmd/Ctrl + Z` 撤销**，并在输入态彻底隔离空格/方向键等全局播放热键与拖蓝选区冲突；
  - `Enter` / 失焦静默落盘为 `.edited.srt`，同步重算词法结构（悬停查词与生词高亮即时生效）并按需增量补齐译文。

### 6. 学习资产跨版本原子保护与迁移
- 当字幕从 L1 升级到 `.local.srt`，或因用户改词、拆句、并句生成/更新 `.edited.srt` 时，旧版本字幕的哈希必然变化。
- 系统在同一次数据库事务中基于「文本词重合 + 时间区间重合」自动完成新旧句子序号锚定，将原有**收藏金句、精析笔记与跟读/听写练习记录**安全迁往新轨道；未改动的句子译文继续 100% 缓存复用。
