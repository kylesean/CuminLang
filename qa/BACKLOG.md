# QA：未自动化与人工测试缺口

> 既有自动化的可执行规格即 `qa/specs/**/*.spec.ts`（可用 `pnpm exec playwright test -c qa/playwright.config.ts --list` 实时查看）。
> 本文件仅记录**尚未自动化**或**依赖外部真机/网络的人工验证项**，不重复抄写已自动化用例。

## 待定 / 未自动化场景

* **外观设置**：启动首帧兜底主题与实际回读主题的一致性（`App.tsx` 首帧兜底）——未覆盖。
* **网络代理**：切回「跟随系统」时自定义地址保留或清空策略（待产品规则定稿）。
* **快捷键**：编辑弹窗内移除单个按键（vs 清空全部）；多动作绑定同一键的冲突提示策略（待产品规则定稿）。
* **跨页自动保存机制**：改动未发出前立刻关窗退出的进程生命周期 flush；保存失败后立刻切走时的跨页错误提示策略。
* **开发态安全边界**：开发态不注入桌面 CSP 属预期（HMR 约束），构建产物安全边界已由 `renderer-security.spec.ts` 覆盖。

## 需外网 / 真机 / 原生弹窗的人工项

* **YouTube 链接导入（8 项）**：受限/私享链接下载失败、排队/下载中取消、连续批量与重复链接防重、关闭弹窗后台完成通知、非法 URL 校验、首页 Hero 与弹窗状态同步——依赖外网与 `yt-dlp` 真实媒体流。
* **服务与资源**：真实云端连通性测试（需真实 Key）、模型包下载与断点测速、真实文件系统清理缓存。
* **手机访问**：真实手机/局域网终端扫码访问与 iOS/Android Web 交互实测（服务端 HTTP 鉴权已由 `mobile-access-settings.spec.ts` 覆盖）。
* **系统集成**：调用系统默认浏览器打开外链（关于页）、调用系统文件管理器打开目录（存储页）、真人眼确认字幕预览观感与真实网络代理流量验证。
