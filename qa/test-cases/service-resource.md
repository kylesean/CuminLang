# 服务与资源

用例文件：`qa/specs/settings/service-resource-settings.spec.ts`（本页所有自动化用例都在这里）

规范与状态含义见 [README.md](./README.md)。

这一页按使用场景分成两个页内分区（写进地址栏 `?tab=`，刷新后仍停在原分区）：

- **本地资源**：硬件能力概览、AI 与识别能力路由、核心视听资源、本地 AI/向量模型、词典与专项扩展；
- **云端服务**：多服务商配置、密钥显式保存、接口地址、API 类型与模型清单。

它把「用哪个模型干哪件事」串在一起，链路最长，也最容易被「改 A 页让 B 页失效」这类问题咬到。

## 填云端服务的密钥、接口地址与模型清单

- 该看到：重进页面后密钥、接口地址都回显，刚添加的模型行还在表格里。
- 用例：**[SET-SVC-01]** 云端服务填写的密钥、接口地址与模型清单会落盘，重进页面仍回显
- 落盘断言：`apiKeys.openAi.key`、`apiKeys.openAi.endpoint`、`models.openai.available`

## 识别方式与词典补充方式

识别方式与功能路由统一展示在「本地资源」分区。

- 该看到：重进页面时分区保持不变，两项选择均来自后端回读。
- 用例：**[SET-SVC-02]** 识别方式与词典补充方式改动会落盘，重进页面仍回显
- 落盘断言：`transcription.engine`、`providers.dictionary`、`models.openai.dictionary`

## 识别方式在两个档位之间往返切

同一个下拉先切到「兼容模式」再切回「硬件加速」。往返是必要的：只切一次的话，
「其实没写盘、只是界面停在最后一次点击」这种错也能过。

- 该看到：每次切换都落盘，重进页面回显最后一次选的档位。
- 用例：**[SET-SVC-03]** 识别方式在兼容模式与硬件加速之间往返切换都落盘，重进页面回显最后一次选择
- 落盘断言：`transcription.engine`

## 用「使用预设」选一个厂商

- 该看到：接口地址与 API 类型当场回填，重进页面仍是这一套。
- 用例：**[SET-SVC-04]** 使用厂商预设会回填接口地址与 API 类型并落盘，重进页面仍回显
- 落盘断言：`apiKeys.openAi.endpoint`、`apiKeys.openAi.apiFormat`
- 断言不从弹窗里写死厂商参数，而是现读预设卡片上的地址与类型，避免厂商参数一改用例就废。

## 模型启用开关与删除

默认未预置云端模型。添加模型后可自由关闭或重新启用（状态显示「已关闭」），不再需要的模型可直接从列表与配置中删除。

- 该看到：新增行开关可切换并落盘，删除后配置与列表均不再保留该模型。
- 用例：**[SET-SVC-05]** 模型可自由启用/关闭与删除
- 落盘断言：`models.openai.disabled`、`models.openai.available`

## 新增云端模型后把字幕翻译指过去

模型清单来自页面详情缓存，保存成功后缓存会立刻刷新，所以新模型不需要重进页面就能在上拉里选中。

- 该看到：下拉里能直接选到新模型；重进页面该功能仍指着它。
- 用例：**[SET-SVC-06]** 把字幕翻译指到新增的云端模型后，模型槽位落盘并回显
- 落盘断言：`models.openai.subtitleTranslation`

## 切换功能到非云端选项与词典路由

已下线的本地轻量翻译引擎不应继续出现在字幕翻译下拉中；词典查询切到云端模型后需持久化，且本地资源区继续呈现英英释义增强包安装入口。

- 该看到：字幕翻译下拉不再提供「本地基础资源包」，切回「关闭」真实落盘；词典查询指向云端模型后槽位落盘并回显。
- 用例：**[SET-SVC-07]** 字幕翻译下拉不再提供已下线的本地轻量引擎，切到关闭后引擎落盘并回显
- 用例：**[SET-SVC-08]** 词典查询切到云端模型后引擎与槽位落盘，本地资源区展示英英释义增强包入口
- 落盘断言：`providers.subtitleTranslation`、`providers.dictionary`、`models.openai.dictionary`

## 整句讲解启停切回「禁用」

未配置模型时默认处于禁用态；绑定模型开启后再切到「禁用」，开关落盘为关闭，重进页面仍是禁用。

- 该看到：开启写盘为 true，切回禁用写盘为 false 并回显禁用。
- 用例：**[SET-SVC-09]** 整句讲解启用后切到禁用，开关落盘为关闭并重进回显
- 落盘断言：`features.openai.enableSentenceLearning`

## 填完接口地址立刻切到别的设置栏目

云端密钥采用显式「保存」防误触覆盖；接口地址等其余表单字段填完随手切走时，必须在组件卸载前冲刷自动保存，不能静默丢失。

- 该看到：切回来时接口地址输入框回显刚才填的值（来自后端回读）。
- 用例：**[SET-SVC-17]** 填完接口地址立刻切到别的设置栏目，改动仍会落盘并在重进后回显
- 落盘断言：`apiKeys.openAi.endpoint`

## 已绑定功能的云端模型也可直接删除

模型管理列表支持自由删除，不再因功能引用而禁用删除按钮。即使用户此前把字幕翻译等
功能绑定到某个云端模型，仍可直接在列表里删除它，重进页面后它不会再回来。

- 该看到：字幕翻译指着某个模型时，该行删除按钮仍可点击；点击删除后 `models.openai.available`
  不再包含该模型，页面与重进后的列表中也不再保留该模型。
- 用例：**[SET-SVC-10]** 已绑定功能的云端模型也可直接删除，删除后列表与配置不再保留该模型
- 落盘断言：`models.openai.available`

## 云端密钥跨重启

- 该看到：关掉应用再打开，密钥框不回传明文，只显示已保存的脱敏占位提示。
- 用例：**[SET-SVC-11]** 关掉应用再打开，云端密钥仍原样回读
- 落盘断言：`apiKeys.openAi.key`

## 把云端模型清单删空

模型清单为空是一个合法状态：用户可以只用本地引擎，也可以把云端配置整个清掉。

- 该看到：删掉列表中新增的最后一个模型后，磁盘上的清单保持为空，重进页面它也不会再出现；
  在这种状态下改「识别方式」这类不使用云端的偏好，仍然正常保存。
- 用例：**[SET-SVC-13]** 把云端模型清单删空后清单保持为空，此时改动偏好仍会正常落盘
- 落盘断言：`models.openai.available`、`transcription.engine`
